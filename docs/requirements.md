# PaperMate Pro - 需求设计文档

## 项目概述

PaperMate Pro 是面向科研人员的智能论文管理平台，集论文阅读、管理、写作、协作于一体，通过 AI 技术提升科研效率。

---

## 一、核心功能模块

### 1. 用户系统

| 功能 | 描述 |
|------|------|
| 注册/登录 | 邮箱注册，密码登录 |
| 个人设置 | 主题切换（浅色/深色/护眼）、语言设置 |
| 研究兴趣 | 设置研究领域，用于个性化推荐 |

### 2. 论文管理（书架）

| 功能 | 描述 |
|------|------|
| 上传论文 | 支持 PDF 上传，自动解析元数据 |
| 导入文献库 | 支持 Zotero、Mendeley、EndNote、BibTeX 导入 |
| 文件夹分类 | 自定义文件夹组织论文 |
| 标签系统 | AI 自动标签 + 手动标签 |
| 状态管理 | 未读、阅读中、已完成 |
| 搜索筛选 | 按标题、作者、标签、状态搜索 |

### 3. 论文阅读

| 功能 | 描述 |
|------|------|
| PDF 阅读 | 分页浏览、缩放控制 |
| 高亮批注 | 文字高亮、添加批注 |
| 书签标记 | 标记重要页面 |
| 阅读进度 | 自动记录阅读位置和进度 |
| AI 问答 | 与 AI 对话讨论论文内容 |
| 导出引用 | 支持 8 种格式（BibTeX、APA、MLA 等） |
| 团队讨论 | 在论文上开展团队讨论 |

### 4. 发现与推荐

| 功能 | 描述 |
|------|------|
| 论文搜索 | 搜索 arXiv、Semantic Scholar 等来源 |
| 分类浏览 | 按研究领域分类 |
| 每日推送 | 根据研究兴趣每日推荐精选论文 |
| 热门论文 | 展示高引用、热门论文 |

### 5. 知识管理

| 功能 | 描述 |
|------|------|
| 知识卡片 | 从论文提取概念、方法、公式 |
| 卡片分类 | 概念、方法、公式、数据 |
| 标签管理 | 多标签组织 |
| 卡片搜索 | 快速检索知识点 |

### 6. 智能功能（AI）

| 功能 | 描述 |
|------|------|
| AI 论文问答 | 与 AI 对话，深入理解论文 |
| 智能文献综述 | 自动生成结构化综述 |
| 论文关系图谱 | 可视化引用关系和研究脉络 |
| 智能写作助手 | 润色、引用推荐、论文检查 |
| 每日论文推送 | 个性化推荐，定时推送 |

### 7. 论文对比

| 功能 | 描述 |
|------|------|
| 多论文对比 | 选择 2-4 篇论文并排对比 |
| 方法对比 | 对比核心方法、实验设置 |
| 结果对比 | 对比实验结果、性能指标 |
| 导出对比表 | 导出对比表格 |

### 8. 投稿管理

| 功能 | 描述 |
|------|------|
| 期刊管理 | 收藏目标期刊/会议 |
| 截稿日追踪 | 会议截稿日提醒 |
| 投稿状态 | 记录投稿、审稿、录用状态 |
| 期刊推荐 | 根据论文内容推荐期刊 |

### 9. 统计分析

| 功能 | 描述 |
|------|------|
| 阅读统计 | 每周/每月阅读数量 |
| 领域分布 | 研究领域分布图 |
| 关键词云 | 研究关键词可视化 |
| 阅读目标 | 设置并追踪阅读目标 |
| 成就系统 | 阅读里程碑成就 |

### 10. 团队协作

| 功能 | 描述 |
|------|------|
| 团队创建 | 创建研究团队 |
| 成员管理 | 邀请成员、权限设置 |
| 共享论文 | 团队共享论文库 |
| 共享批注 | 查看团队成员批注 |
| 团队讨论 | 论文讨论区 |

### 11. 离线功能

| 功能 | 描述 |
|------|------|
| 离线下载 | 下载论文供离线阅读 |
| 下载管理 | 管理已下载论文 |
| 存储统计 | 本地存储空间统计 |

---

## 二、用户角色

| 角色 | 权限 |
|------|------|
| 普通用户 | 个人论文管理、AI 功能、统计分析 |
| 团队管理员 | 团队管理、成员邀请、权限设置 |
| 团队成员 | 团队论文访问、共享批注、讨论 |

---

## 三、技术要求

### 性能要求
- 页面加载 < 2s
- PDF 渲染流畅
- AI 响应 < 5s

### 安全要求
- 用户数据加密存储
- API 认证授权
- 文件上传安全检查

### 兼容性
- 桌面端：Chrome、Firefox、Safari
- 移动端：iOS、Android 浏览器
- 响应式设计
